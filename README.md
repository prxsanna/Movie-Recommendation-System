# 🎬 Movie Recommendation System

A content-based movie recommender built using the TMDB 5000 Movie Dataset.  
This project uses movie metadata such as genres, keywords, cast, crew, and overviews to recommend similar movies.

## 📌 Features

- Merges and preprocesses movie and credit data
- Extracts and cleans relevant fields (genres, cast, crew, etc.)
- Generates tags for each movie by combining important features
- Converts text data into numerical vectors using NLP techniques
- Computes movie similarity using cosine similarity
- Recommends top 5 similar movies based on user input

## 🧠 Technologies Used

- Python (Pandas, NumPy, AST)
- Natural Language Processing (NLP)
- Content-Based Filtering

## 📁 Dataset

- [TMDB 5000 Movie Dataset](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata)

## 🚀 How to Use

1. Load the datasets
2. Run the preprocessing steps
3. Use the recommender function to get similar movies

## 📬 Output

Given a movie name, the system returns 5 recommended titles that are most similar in content.
